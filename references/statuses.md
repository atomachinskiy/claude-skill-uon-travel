# Справочники статусов

Статусы в U-On настраиваются каждым кабинетом отдельно. Ниже — **дефолтный набор**, который видим в свежем кабинете. У клиента могут быть переименованы или добавлены свои.

Получить актуальный список:

```bash
uon statuses requests
uon statuses leads
uon statuses pay
uon statuses cb       # для схемы работы Центрального бронирования
```

---

## Статусы заявок (`/status`)

| id | Название | is_archive | is_cancel | is_confirmed |
|----|----------|:----------:|:---------:|:------------:|
| 7 | Новая | 0 | 0 | 0 |
| 1 | В работе | 0 | 0 | 0 |
| 8 | Документы готовы к выдаче | 0 | 0 | 1 |
| 2 | Подтверждена | 0 | 0 | 1 |
| 5 | Документы выданы | 1 | 0 | 1 |
| 6 | Заявка закрыта | 1 | 0 | 1 |
| 3 | Отказ | 1 | 1 | 0 |
| 4 | Аннулирована | 1 | 1 | 0 |
| 9 | Заявка → Лид | 0 | 0 | 0 |

**Поля:**

- `is_archive` — статус помечает заявку как «архивную» (не отображается в активной воронке)
- `is_cancel` — статус — отказной (учитывается в метрике конверсии как отрицательный)
- `is_confirmed` — заявка подтверждена клиентом (для метрик выручки)

**Воронка по дефолту:** Новая → В работе → Подтверждена → Документы готовы → Документы выданы → Заявка закрыта. Или → Отказ / Аннулирована.

## Статусы по бронированию ЦБ (`/status_cb`)

Только при включении схемы работы "Центральное бронирование" (для туроператоров). По дефолту пусто.

---

## Маппинг status → бизнес-смысл (для BI)

Чтобы построить воронку из API-данных, используем поля `is_archive` / `is_cancel` / `is_confirmed`:

| Стадия воронки | Условие |
|----------------|---------|
| Активная заявка | `is_archive=0` |
| Подтверждена клиентом | `is_confirmed=1` |
| Закрыта успешно | `is_archive=1 AND is_cancel=0` |
| Отказ | `is_cancel=1` |
| Lead-конверт | `id=9` (Заявка → Лид — обратная конверсия) |

Эту логику используем в `scripts/stats.py` для воронки.

---

## Кастомные статусы клиента

Если клиент создал свои статусы, маппинг делается через `is_archive/is_cancel/is_confirmed` — эти поля стандартные для всех. Названия могут быть «Жду оплату», «У туроператора», «Анкета заполнена» — это всё ещё либо `archive=0` (в работе), либо `archive=1` (завершена).
